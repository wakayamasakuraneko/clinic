# 料金表v2 作業記録（2026-10-13〜10-17）

トップページ（`index.html`）の料金表に「個数を入れると合計が出る」計算機能を付けた作業の記録です。作業の途中で、料金表の土台そのものを作り直しました（v2）。

---

## 1. 見た目・機能で変わったこと

### 計算機能（新規）
- **個数欄**：各料金の右に個数欄（▲▼ボタン付き）を追加しました。個数を入れた行は色が反転します。
- **合計欄**：画面の下に張り付きます。税抜・税込の合計を表示し、税切替ボタンに連動します。
  - 「小計表示」ボタンで、内訳（項目名・個数・金額）が開きます。開いている間は「小計非表示」に変わります。
  - 内訳の各行の「−」「＋」で個数を増減、「×」でその項目を削除（個数0）できます。表の個数欄にも連動します。
  - 「～」付きの項目（堕胎費・入院費）を選ぶと、合計も「下限～上限」で出ます。
  - 注意書きとして「※ あくまで目安です。猫の状態による追加処置で、表示額より多くなることがあります。」を表示します。
  - 「リセット」ボタンで、全項目の個数を0に戻せます。
- **料金表開閉ボタン**：表の右上にあり、スクロールすると上部ナビのすぐ下に張り付きます。押すたびに全部開く／全部閉じるを繰り返します。
- **税切替ボタン**：合計欄の中に移しました。見出しの「税抜」バッジは表示のみです。

## 2. 仕組みで変わったこと（v2）

旧料金表は「行の高さを行間で作る」「開閉も行間を0にして潰す」作りでした。そのため、折り返しや要素の追加のたびに崩れやすい状態でした。v2では土台から作り直しています。

| 項目 | 旧 | v2 |
|---|---|---|
| 表のHTML | `price-main.htm` / `price-discount.htm` に手書き | `price-table.json` からJSで自動生成 |
| 行の高さ | 行間（2.5〜3）。折り返すと広がる | 余白（padding）。折り返しても崩れない |
| 開閉 | 行間を0にして潰す | 高さを 0 ⇄ 中身 で動かす（grid 0fr ⇄ 1fr） |
| 税切替 | 要素の並び順に依存 | 税抜・税込を両方書き、CSSで出し分け |
| 広げるボタン | ボタンの文字（「折り畳む」か）で判定 | 状態を直接見て判定 |
| JS | 7本（loader・アコーディオン系5本・料金反映） | `price-table.js` 1本 |
| 割引料金の表 | 手書き | JSONの料金から自動生成 |

おまけで、旧料金表で起きていた不具合も解消しました。行間を詰めるスクリプト（`line-height-adjustable.js`）は、読み込みのタイミングの都合で一度も動いておらず、スマホで折り返した見出しの行間が広いままになっていました。

### 使っているファイル
| ファイル | 役目 |
|---|---|
| `price/data/price-table.json` | **表の構成**：見出し・行・説明文。項目の追加・名前変更・並べ替え・非表示はここだけ直せばよい |
| `price/data/price-data.json` | **料金の数字**（旧料金表と共通） |
| `price/data/antiworm-data.json` | 駆虫薬の比較表（旧料金表と共通） |
| `js/price-table.js` | 表の組み立て・開閉・税切替・計算・ノミの演出 |
| `css/price-table.css` | 見た目。料金表の上下の注意書き（`.price-caption`）もここに移した |

`price-table.json` の書き方は、ファイル先頭の `_説明` と `price/README.md` を参照してください。

## 6. 注意点・残っていること

- **耳カット料金**：「通常料金 − 500円」の計算ではなく、JSONに直接 8000・5000 と書いています。手術料金や耳カット割引を変えるときは、この2項目も直してください。
- **アニメーションの設定**：パソコンの「アニメーション効果」がオフでも、料金表の演出は止めない設定にしています（`css/price-table.css` の末尾にコメントあり）。
- **表記ゆれ**：駆虫薬の比較表（`antiworm-data.json`）の名前は「ネクスガードCat」のままです。料金表は「ネクスガードCAT」です。
- **割引料金**：合計の計算には含めていません（耳カットとワクチンの頭数割引は、表として表示するだけ）。
- **おすすめセット**：旧料金表でコメントアウトされていた「外猫おすすめセット・保護猫おすすめセット」は、v2には入れていません。
- **公開範囲**：このmdと `price/README.md` は、GitHub Pagesでも公開される場所にあります（機密情報は含んでいません）。
